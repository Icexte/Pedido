# 💕 Site de Pedido de Namoro

Site romântico de página única, personalizado para Ice e Moon Stone, feito com HTML, CSS e JavaScript puro.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie todos os arquivos deste ZIP para o repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **GitHub Actions**.
5. O workflow incluído em `.github/workflows/pages.yml` fará a publicação.
6. Depois que o Actions terminar, o GitHub mostrará o endereço do site.

## Personalização

Abra `index.html` e altere:
- Os textos da surpresa.
- O nome na assinatura.
- A carta.

Para adicionar fotos, coloque imagens na pasta `assets/` e insira elementos `<img>` no HTML.

### Música

Você pode colocar um arquivo de música em `assets/musica.mp3` e adicionar um player no HTML. Evite músicas protegidas por direitos autorais se você não tiver autorização para usá-las.

## Estrutura

- `index.html` — conteúdo do site
- `style.css` — visual e animações
- `script.js` — interações e confetes
- `.github/workflows/pages.yml` — publicação automática no GitHub Pages
- `assets/` — espaço para fotos e outros arquivos
